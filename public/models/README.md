# AURA SKINCARE 3D Model Asset Location

Place your exported Blender 3D particle sphere file here:
`/public/models/aura_sphere.glb`

Alternative supported formats:
- `/public/models/aura_sphere.gltf` (with embedded buffers)

When this file is present, the AURA web application will automatically load your custom 3D model, set up the camera framing, and play any embedded idle animations via Three.js AnimationMixer.

You can also test your model immediately by dragging and dropping your `.glb` file into the "3D Model Asset" panel in the running web application.
